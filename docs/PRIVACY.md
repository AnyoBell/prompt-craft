# What this site collects

Only anonymous usage events: page view, which module or FAQ was opened, whether the prompt builder was used (never what was typed), which section was reached, and whether a reserve button was clicked.

Each visit gets a random ID that lives in the browser tab only (sessionStorage) and disappears when the tab closes. No cookies, no IP addresses stored, no names or emails. Referrer is reduced to a hostname, country is coarse, device is mobile/tablet/desktop.

The tracker does nothing when the browser sends Do Not Track, or when no endpoint is configured.

If you run your own copy, tell your visitors what you collect, and check your college's policy on student data before enabling it.
